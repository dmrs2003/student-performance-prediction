# 🎓 Student Performance Prediction using Machine Learning

A modern Machine Learning web application that predicts student exam performance based on academic behavior, study habits, and learning-related factors.

## 🚀 Features

* 📚 Predicts student exam scores using Machine Learning
* 🎨 Modern Streamlit UI dashboard
* 📊 Interactive input fields and sliders
* 🤖 Random Forest Regression model
* 📈 Data preprocessing and feature encoding
* 🔍 Real-time prediction system

---

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Matplotlib

---

## 📂 Dataset Features

The model uses multiple student-related factors such as:

* Hours Studied
* Attendance
* Previous Scores
* Sleep Hours
* Tutoring Sessions
* Motivation Level
* Internet Access
* Extracurricular Activities
* Parental Involvement
* Access to Resources
* Parental Education Level

---

## 🤖 Machine Learning Model

### Random Forest Regressor

The project uses a Random Forest Regressor to predict student exam scores based on academic and behavioral data.

---

## 📊 Model Performance

* R² Score: 0.62
* MAE: 1.18
* RMSE: 2.43
* Model Accuracy: 62.01%

---

## 🖥 Streamlit UI

The project includes a fully interactive and modern Streamlit web application where users can:

* Enter student details
* Adjust academic factors
* Predict exam scores instantly
