# 🎓 Student Performance Prediction

Machine learning project that predicts student academic performance using Python and Scikit-learn.

## 🚀 Features
- Data preprocessing
- Machine learning model training
- Prediction system
- Data visualization
- Accuracy evaluation

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## 📊 Model
Random Forest Regressor

## 📷 Output
The model predicts student math scores based on academic and demographic data.
